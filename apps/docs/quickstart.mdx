## Prerequisites

- macOS or Linux (arm64 or amd64).
- Claude Code.
- A token for at least one provider you use. `muretto init` tells you which permissions to give it.

## Get started

<Steps>
  <Step title="Install">
    There is no tagged release yet, so install from source. You need Go 1.27.3 or newer.

    ```bash
    go install github.com/tolgayayci/muretto/cmd/muretto@latest
    ```

    From v0.1.0, `npm install -g muretto`, `brew install tolgayayci/tap/muretto` and the `install.sh` script will also work.
  </Step>
  <Step title="Add the hooks and connect providers">
    ```bash
    muretto init
    ```

    `init` adds Muretto's hooks to your Claude Code settings (it makes a backup first), then asks, provider by provider, whether to connect it. It shows the least-privilege token to create, and stores the token in your OS keychain.

    In CI or without a terminal, set `MURETTO_<PROVIDER>_TOKEN` (for example `MURETTO_SUPABASE_TOKEN`) and run `muretto init --yes`.
  </Step>
  <Step title="Work as usual">
    Use Claude Code as you normally do. The hooks record each tool call locally. They never block the agent.
  </Step>
  <Step title="See what was created">
    ```bash
    muretto                  # summary: agent-created, exposed, needs review, recent sessions
    muretto sessions         # recent agent sessions
    muretto exposed          # exposure findings, worst first
    muretto why customers    # the evidence behind an attribution label
    ```

    Every read command takes `--json`.
  </Step>
</Steps>

## Other commands

| Command | What it does |
|---|---|
| `muretto session <id>` | Everything one session created |
| `muretto resources [--provider p] [--exposed] [--unknown]` | Resources, filtered |
| `muretto show <resource>` | One resource: timeline, creator, exposure, cost, review |
| `muretto review [<resource> keep\|not-needed]` | Record whether you still need a resource |
| `muretto providers --coverage` | What each provider adapter covers |
| `muretto doctor` | Check hooks, tokens, spool and last checks |
| `muretto uninstall` | Remove exactly what `muretto init` added |

## Getting help

Run `muretto doctor` first. If something still looks wrong, open an issue on [GitHub](https://github.com/tolgayayci/muretto/issues).
