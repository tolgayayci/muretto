---
title: "Introduction"
description: "Muretto shows what your AI coding agents created outside the repo. It is open source and read-only."
---

Coding agents like Claude Code create real infrastructure: tables, storage buckets, functions, deployments, webhooks. Your repo shows the code they wrote. It doesn't show what they made in your provider accounts.

Muretto is a command-line tool that:

- **lists** the resources in your connected provider accounts;
- **traces** each one to the agent session and the tool call that created it, or labels it **creator unknown**;
- **flags** what is open to anyone on the internet.

It is read-only. It never creates, changes or deletes anything in your accounts.

```text
$ muretto session 8f2a
Session 8f2a · alice · Claude Code · Oct 19 14:02–14:31
Task: "add customer import with file uploads"
Repo: acme/web (feat/import)

  SUPABASE  project acme-dev
  ✓ table      customers        exact   ⚠ RLS off: publicly readable
  ✓ bucket     customer-files   exact   ⚠ public
  ✓ function   process-import   exact
  ✓ branch     import-test      exact   7 days old · review due

  VERCEL  project acme-web
  ✓ deployment preview-a81f     exact   ⚠ public preview

  3 exposed · 1 needs review · checked 3 min ago
  → muretto why customers
```
