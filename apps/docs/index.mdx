Coding agents like Claude Code create real infrastructure in your provider accounts: tables, storage buckets, functions, deployments, webhooks. Your repo shows the code they wrote, but not what they left running in those accounts.

Muretto is an open-source command-line tool that shows you. Here is one agent session, traced:

```text
$ muretto session 8f2a
Session 8f2a · alice · Claude Code · Oct 19 14:02–14:31
Task: "add customer import with file uploads"
Repo: acme/web (feat/import)

  SUPABASE  project acme-dev
  ✓ table      customers        exact   ⚠ RLS off: publicly readable
  ✓ bucket     customer-files   exact   ⚠ public
  ✓ function   process-import   exact
  ✓ branch     import-test      exact   7 days old · review due

  VERCEL  project acme-web
  ✓ deployment preview-a81f     exact   ⚠ public preview

  3 exposed · 1 needs review · checked 3 min ago
  → muretto why customers
```

In one command you see the task alice gave the agent, the five resources it created, and the three that anyone on the internet can reach.

## What Muretto does

- **Lists** the resources in the provider accounts you connect.
- **Traces** each one to the agent session and tool call that created it. If the evidence is not clear, it labels the resource **creator unknown**.
- **Flags** what is exposed: open to anyone on the internet, such as a table anyone can read (RLS off), a public bucket or a public preview.
- **Shows its evidence.** `muretto why <resource>` prints the tool call behind every label.

## What Muretto never does

Muretto is read-only. It never creates, changes or deletes anything in your accounts, and it never runs a command for you.

- Every provider request goes through one module that refuses anything but an allowlisted read.
- The hooks it adds to Claude Code only record. They never block or change the agent.
- Your data stays on your machine unless you turn on the optional [dashboard](/dashboard) sync.

## Supported today

| | |
|---|---|
| Agent | Claude Code |
| Providers | Supabase, Vercel, GitHub, Cloudflare, Neon, Stripe, Render, PlanetScale |
| Platforms | macOS and Linux, arm64 and x64. Windows through WSL |

<Note>
Supabase and Vercel are checked against live accounts. The other six providers are built from each provider's documented API and tested offline, not yet against a live account. See [Providers](/providers).
</Note>
